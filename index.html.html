👥 ภาระงานรายคน
ตัวเลข = จำนวนงานที่ยังไม่เสร็จและมีช่วง Plan คาบเกี่ยวกับสัปดาห์นั้น · งานที่เลยกำหนดแต่ยังไม่ปิดจะนับต่อเนื่องถึงสัปดาห์ปัจจุบัน · แดง = ถึงเกณฑ์งานล้น · คลิกช่องเพื่อดูรายการ · คลิกชื่อเพื่อดูในแผนงาน
📣 ประกาศ
✅ งานรออนุมัติ User กรอก 100% / เสร็จสิ้น → ระบบส่งเป็น "รอตรวจสอบ" · Admin อนุมัติแล้วจึงปิดงาน หรือตีกลับพร้อมเหตุผล
งานผู้รับผิดชอบPlan%ส่งตรวจเมื่อหมายเหตุ

👥 รายชื่อผู้รับผิดชอบและแผนก

พิมพ์ บรรทัดละ 1 รายการ · เก็บในชีต Config ของไฟล์นี้ — เพิ่ม/ลบคนหรือแผนกได้ทันที ไม่ต้องแก้โค้ดหรือแจกไฟล์ใหม่
รายการงานเดิมที่ใช้ชื่อที่ถูกลบออก จะยังเก็บชื่อนั้นไว้ (แค่ไม่โผล่ในตัวเลือกใหม่) · การเปลี่ยนชื่อคน = เพิ่มชื่อใหม่ แล้วแก้ผู้รับผิดชอบของงานเอง

📥 นำเข้าข้อมูลจาก ProjectFlow เดิม

อ่านจากชีต Tasks และ Projects ในไฟล์ Google Sheet นี้ (ชีตเดิมไม่ถูกแก้ไขหรือลบ) ใช้ ID คงที่ จึงกดซ้ำได้ปลอดภัย — ค่าเริ่มต้นจะข้ามรายการที่เคยนำเข้าไปแล้ว
⚠️ ข้อมูลเดิมไม่มีประวัติสถานะจริง ระบบจึงประมาณ % และวันที่ Actual จากสถานะ (ระบุไว้ในช่องหมายเหตุของแต่ละรายการ) ควรตรวจแก้ภายหลัง

🔒 การล็อก Plan (Baseline)

ใช้ปุ่ม 🔒 ในหน้าต่างรายละเอียดของ Master Plan (เฉพาะระดับอนุมัติ) — ระบบบันทึกวันที่ Plan ปัจจุบันของทั้งแผนผังเป็น Baseline
หลังล็อก ผู้ใช้ทั่วไปแก้วัน Plan / เพิ่ม-ลบรายการไม่ได้ แต่ยังอัปเดต Actual รายสัปดาห์ได้ตามปกติ · ผู้อนุมัติยังปรับ Plan ได้ และระบบจะแสดงส่วนต่างจาก Baseline

📸 Snapshot SPI และ ✉ สรุปรายสัปดาห์

Snapshot บันทึกค่า Plan% / Actual% / SPI ของทุก Master Plan ลงชีต Snapshots เพื่อวาดกราฟแนวโน้มในหน้า "ภาพรวม" (รันซ้ำวันเดียวกันจะทับของเดิม)
สรุปรายสัปดาห์ ส่งทางอีเมล (และ LINE ถ้าตั้งค่าไว้) เป็นรายการงานรออนุมัติ / เลยกำหนด / ค้างอัปเดตรายคน
ให้ทำงานอัตโนมัติทุกวันศุกร์: ใน Apps Script รัน setupDigest() แล้ว installWeeklyTrigger() อย่างละ 1 ครั้ง

⚠️ ออฟไลน์ — รอเชื่อมต่ออินเทอร์เน็ต (ร่างที่กรอกไว้ยังอยู่ในเครื่อง)
